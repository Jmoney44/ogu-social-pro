# Ogu Social Pro

Portfolio website for Johnson Ogu, social media manager.

- `index.html`: the website (single page, no build step)
- `videos/`: sample post videos and their cover images

## Run locally
Open `index.html` in a browser.

## Hosting
Works on any static host (GitHub Pages, Netlify). Keep the `videos` folder next to `index.html`.
